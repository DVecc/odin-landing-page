# Odin Landing Page

This project is a responsive landing page built as part of The Odin Project Foundations curriculum. The goal was to create a polished, modern-looking webpage from scratch using HTML and CSS, with a focus on layout, typography, spacing, and visual hierarchy.

## Project Overview

The landing page includes a professional structure with:

- A header and navigation section
- A hero area with a strong call-to-action
- An information section with featured content
- A quote/testimonial section
- A final call-to-action and footer

## What I Learned

This project helped strengthen skills in:

- Building semantic HTML structure
- Styling with CSS for layout and consistency
- Using Flexbox to arrange page sections
- Creating a clean visual design from a reference

## Technologies Used

- HTML5
- CSS3

## How to View the Project

1. Open the project folder in your preferred code editor.
2. Launch the page by opening the index.html file in your browser.
3. Alternatively, use a live preview extension for a smoother development experience.
